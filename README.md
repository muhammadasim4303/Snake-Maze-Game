# Snake Maze Game (Pygame + A* Pathfinding)

This is a Python-based Snake game built with Pygame that uses the A* pathfinding algorithm. The snake autonomously finds its way to food while avoiding randomly generated obstacles on the screen.

## 🧠 Features

- A* pathfinding algorithm for snake movement
- Randomly generated maze-like obstacles
- Collision detection with walls, obstacles, and self
- Score tracking
- Game restart functionality after losing
- Color-coded graphics using Pygame

## 🎮 How to Play

- Run the game using Python.
- The snake will automatically move toward the food.
- Avoid obstacles and the snake's own body.
- If there's no path to the food, the game ends.
- Press `C` to play again or `Q` to quit when the game ends.

## 🛠 Requirements

- Python 3.x
- Pygame (`pip install pygame`)
